## Gitファイル変更コマンド
| Command | Description |
| --- | --- |
| `git status` | ファイルの変更状況を確認|
| `git diff` | 変更した内容を確認 |
| `git add .` | すべての変更ファイルをステージング |
| `git add <filename>` | 指定したファイルをステージング |
| `git commit -m "message"` | 変更をコミット |
| `git commit` | エディタを開いてコミットメッセージを入力 |
| `git push` | GitHubに変更を反映 |
| `git pull` | GitHubの最新の変更を取得 |
| `git log --oneline` | コミット履歴を確認 |
