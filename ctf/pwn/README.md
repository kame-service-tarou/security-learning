# pwnのためのツール
## pwndbg
GDBをCTFのpwn向けに使いやすく拡張したツールです。

### 得られる情報
プログラムを実行して停止すると、以下のような情報を確認できる。
・Registers:レジスタの値
・Stack:スタックの内容
・Disassembly:アセンブリ命令
・Backtrace:関数呼び出しの履歴
・Memory:メモリの内容

また、次のコマンドを実行してみる。
```GDB
checksec
```
これによるとバイナリのセキュリティ機構を確認できる。
代表的な項目は以下のとおり。
| 項目 | 意味 |
| --- | --- |
| RELRO | GOTなどの保護|
| Stack | Stack Canaryの有無 |
| NX | スタック上のコード実行制限 |
| PIE | 実行ファイルのロード位置のランダム化 |

### 基本的なデバッグ操作
GDBには、プログラムの実行を止めたり、1行ずつ進めたりする機能がある。

| コマンド | 意味 |
| --- | --- |
| ``break main`` | main関数にブレイクポイントを設定 |
| ``run / r`` | プログラムを実行 |
| ``continue / c`` | 次のブレイクポイントまで実行 |
| ``next / n`` | 次のソースコード行へ進む |
| ``step / s`` | 関数の中に入って進む |
| ``nexti / ni`` | 次のアセンブリ命令へ進む(関数呼び出しには入らない) |
| ``stepi / si`` | 次のアセンブリ命令へ進む(関数呼び出しにも入る) |
| ``finish`` | 現在の関数が終了するまで実行 |
| ``quit / q`` | GDBを終了 |

## solve.pyで使うpwntoolsの関数
| 関数 | 意味 |
| --- | --- |
| ELF() | ELFファイルを解析 |
| process() | ローカル実行 |
| remote() | リモート接続 |
| send() | データを送信 |
| sendline() | 改行付きで送信 |
| recv() | データを受信 |
| recvuntil() | 1行受信 |
| interactive() | 対話モード |
| p64() | 64bit整数をバイト列に変換 |
| u64() | バイト列を64bit整数に変換 |
| cyclick() | 一意なパターンを生成 |
| cyclic_find() | パターンからオフセットを調べる |
