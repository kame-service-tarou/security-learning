# OverTheWire
Linuxの操作からWebセキュリティ、暗号、バイナリ解析、脆弱性攻撃まで、実戦形式で学べるサイトです。

- [Bandit:Linuxの基本操作やCommands Lineの使い方を学ぶ.](./Bandit/)
- [Natas:HTTP通信やWeb Applicationの仕組みを理解し、脆弱性を発見するための基礎を身につける.]
- [Leviathan:実行ファイルの挙動を調査し、Programがどのように動作しているかを理解する.]
- [Krypton:暗号化・復号の仕組みとCryptanalysis(暗号解読)を学ぶ]
- [Narnia:MemoryやStackの仕組みを理解し、Buffer Overflowなどの脆弱性を解析できるようになる。]
- [Behemoth:実際のProgramに存在する脆弱性を調査し、Exploitの考え方を身につける。]
- [Utumno:低レベルのProgramの動作を理解し、より高度な脆弱性解析に挑戦する。]
- [Maze:Programの内部構造を解析し、複雑な問題を解決する力を身につける。]
- [Vortex:コンピュータ内部のデータ表現やProgramの動作を理解する。]
- [Manpage:公式Documentationを読み、必要な情報を自分で調べる力を身につける。]
- [Drifter:低レベルのProgramやシステムの動作について理解を深める。]
- [FormulaOne:Programの動作やChallengeの構造を調査し、問題解決能力を高める。]
- [Semtex:Network通信やBinaryの仕組みを理解し、脆弱性を発見・解析する力を身につける。]
- [HES2010:Webサイトから情報を収集し、Serverの構造や脆弱性を調査する力を身につける。]
- [Abraxas:実際の環境を調査するように、情報収集から脆弱性のへっ件までの流れを経験する。]
- [Monxla:Web ServerやLinux環境を調査し、隠された情報を発見するための技術を身につける。]
- [Kishi:複数のLinux環境やContainerの構造を理解し、Web ServerやNetWork Servicesを調査する力を身につける。]
